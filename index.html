    Pour une voix vraiment naturelle

    • PC : ouvre le site avec Microsoft Edge : il propose les voix neuronales « Denise », « Henri », « Vivienne »… (marquées ★).
    • Android : Chrome + « Services Google pour la synthèse vocale » ; télécharge la voix française haute qualité dans les réglages du téléphone.
    • iPhone / iPad : Réglages → Accessibilité → Contenu énoncé → Voix → Français : télécharge une voix « Premium » ou « Améliorée ».
